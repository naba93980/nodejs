#### Node.js Web API - Without a Framework

A learning exercise exploring how to build a web API using Node.js without relying on a web framework such as Express.

#### Topics

- Creating an HTTP server with Node.js
- Handling incoming requests and outgoing responses
- Routing and endpoint handling
- Processing request data
- Returning API responses
- Understanding the fundamentals behind web frameworks

#### Getting Started


Ensure nodemon is installed, then install any project dependencies if required.

```bash
cd web-api
npm start
```
